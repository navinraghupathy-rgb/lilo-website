# liloapp.de, the live website

The public website of Lilo: `index.html`, `impressum.html`, `datenschutz.html`.
No cookies, no tracking, no forms, no outside fonts. Keep it that way unless the
privacy page is updated at the same time.

## Where it runs

- **Now (from 14 October 2026):** GitHub Pages, free, from the repository
  `lilo-website` on the owner's GitHub account. `CNAME` tells GitHub to serve the
  site at liloapp.de.
- **Domain and email:** stay at IONOS. contact@ and kontakt@liloapp.de forward to
  the owner's Gmail. Never change the MX records of liloapp.de or reply.liloapp.de,
  or the Brevo records.

## Move to IONOS later

The owner's decision: move the site to IONOS web hosting when the time is right
(after the loan, or before the pilot at the latest), so everything is with one
provider in Germany. Then:

1. Book a small IONOS web hosting package and upload the three HTML files.
2. Point liloapp.de at the IONOS webspace instead of GitHub's addresses.
3. In `datenschutz.html`, section 2: replace GitHub with IONOS hosting.
4. Switch off GitHub Pages and delete `CNAME`.
